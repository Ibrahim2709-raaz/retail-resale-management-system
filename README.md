# Retail Resale Management System

A full-stack retail management platform being developed for a real clothing resale business.

## Project Status

**Current Phase:** Technical Design

### Completed

- Project initialization
- Requirements engineering
- System context modeling
- Use case modeling
- Detailed use case specifications
- Conceptual domain modeling
- Process and activity modeling

### In Progress

- Logical data modeling
- Entity Relationship Diagram (ERD)
- Technical architecture design

Implementation has not yet begun.

---

## Problem

The business currently manages purchasing, inventory, customers, credit sales, payments, deliveries, expenses, and sales records through a combination of spreadsheets, handwritten records, and WhatsApp.

This creates several challenges:

- limited visibility into inventory;
- difficult tracking of customer credit and outstanding balances;
- inconsistent profit and cost tracking;
- fragmented customer and sales history;
- manual delivery tracking;
- limited reporting and analytics;
- difficulty scaling the business.

The goal of RRMS is to consolidate these operations into a centralized software platform and later support a customer-facing online storefront.

- Sales

- Deliveries
- Returns
- Exchanges

- Receipts
- Reporting and analytics

A customer-facing storefront is part of the longer-term product vision.

## Project Approach

The project is being developed using a structured software-development lifecycle rather than immediately beginning implementation.

The current process includes:

1. Project initialization
2. Requirements engineering
3. System modeling
4. Technical design
5. Implementation
6. Testing
7. Deployment
8. Maintenance and future improvements

Requirements and system behavior are documented before database, backend, and frontend implementation begins.
